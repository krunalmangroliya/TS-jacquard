## Generation prompt

Use case: illustration-story. Asset type: reference PNG for a jacquard textile tracing software prototype. Create one clean black-and-white line-art repeat unit for an Indian saree butta: a single elegant medium-complexity paisley (keri) with a six-petal flower inside, a curved stem and two leaves, a few small enclosed teardrop ornaments. Square canvas, full motif centered with 10% plain white margin on every side; no motif crosses the canvas border. Pure black uniform thin strokes on pure white. Every petal, leaf, paisley outline and ornament must form a completely closed region; connected interior lines end exactly at boundaries. Spacious readable shapes for automatic centerline tracing. Include 3-5 tiny closed decorative circles as deliberate optional minor details for small-size simplification tests. No filled black areas, gray shading, hatching, texture, gradients, text, watermark, border, paper, shadows or perspective. Flat crisp technical textile drawing, about 2048 by 2048 pixels if possible. This is art for software testing, not an interface mockup.
